# Spec notes

Gaps, conflicts and risks found between PLAN.md, CLAUDE.md, the platforms and the data sources, and what was decided. Rows marked **Owner to confirm** use a default until the owner answers.

Types: `gap` (not specified), `conflict` (two sources disagree), `risk` (could go wrong later).

| ID    | Type     | Finding                                                                                                                                 | Decision                                                                                                                                                                                                                            |
| ----- | -------- | --------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| N-001 | conflict | CLAUDE.md makes PLAN.md the tracker; project-flow tracks work in `docs/backlog.md` and GitHub issues. Two trackers drift.               | PLAN.md stays the product spec (vision, features, reference data, small decisions). Status lives only in GitHub issues and `docs/backlog.md`. PLAN.md §4 keeps the phase scope without checkboxes. CLAUDE.md updated. See ADR-0010. |
| N-002 | gap      | Supported date range is not stated. PLAN.md says the 11/12 September rule is "valid 1900–2099", but the JDN formulas work for any year. | Year ≥ 1 in every calendar is accepted. Earlier years throw `InvalidDateError`. Exhaustive tests cover 1900–2100; spot checks cover year 1 and year 9999. The 11/12 September note is descriptive only.                             |
| N-003 | gap      | Ethiopian era: Amete Mihret or Amete Alem (`Intl` has both `ethiopic` and `ethioaa`).                                                   | Amete Mihret only. Amete Alem can be added later as a format option, not a calendar.                                                                                                                                                |
| N-004 | gap      | `fromJSDate`: a JS `Date` is an instant, not a day. Which time zone decides the day?                                                    | Default is the `Date`'s local calendar day (what the user sees). Option `{ utc: true }` uses the UTC day. An IANA `timeZone` option waits until a consumer needs it.                                                                |
| N-005 | conflict | Ethiopian time counts hours from 6:00, and the Hijri day traditionally begins at sunset. PLAN.md does not say when the date changes.    | The date changes at civil midnight in all three calendars, matching `Intl` and government use. Ethiopian time changes only the hour display. Docs state that the Islamic day begins at the previous sunset. **Owner to confirm.**   |
| N-006 | risk     | Tabular Hijri has variants (leap year 15 vs 16 in the cycle).                                                                           | Use PLAN.md's list (16), which matches ICU `islamic-civil`, so the `Intl` cross-check is meaningful.                                                                                                                                |
| N-007 | risk     | `Intl` calendar data differs between ICU versions and Node builds with small ICU.                                                       | Runtime code never depends on `Intl` calendars. The Umm al-Qura table is generated once and committed. Cross-check tests run on Node with full ICU; the CI log prints the ICU version.                                              |
| N-008 | conflict | PLAN.md makes Umm al-Qura the default Hijri method but schedules it for Phase 5, after `@qen/core@0.1.0` ships.                         | 0.x releases default to tabular and say so in the README. 1.0 switches the default to Umm al-Qura as a documented breaking change. **Owner to confirm**; the alternative is moving T-060/T-061 into M1.                             |
| N-009 | conflict | CLAUDE.md wants the Umm al-Qura table importable separately, but as the 1.0 default it would always be loaded.                          | Encode the table compactly (start JDN + one bit per month length, about 1 KB) in its own module. Apps that never touch Hijri do not import it. Revisit if size-limit shows otherwise.                                               |
| N-010 | gap      | Hijri dates are plain objects, but the same Hijri y/m/d maps to different days under different methods.                                 | The date object carries no method. Every function that maps Hijri ↔ JDN takes `HijriSettings` (default per N-008). Results from the adjustment pipeline report the deciding step.                                                   |
| N-011 | gap      | `parse("17/01/2019")` without a marker could be Gregorian or Ethiopian.                                                                 | If `calendar` is given, use it. If the input has a marker (EC, AH, a month name, script), detect it. Otherwise throw a typed `AmbiguousDateError` listing candidates. The final API shape goes in an ADR with T-029.                |
| N-012 | gap      | `format()` pattern syntax is not specified.                                                                                             | Unicode LDML tokens (`yyyy`, `MM`, `MMMM`, `d`, `EEEE`) so they match what developers know from `Intl` and date-fns. ADR with T-028.                                                                                                |
| N-013 | gap      | Day clamping rules for every calendar.                                                                                                  | Clamp to the last valid day: Hamle 30 + 2 months → Pagume 5/6; Pagume 6 + 1 year → Pagume 5; Hijri 30 → 29 in a 29-day month.                                                                                                       |
| N-014 | gap      | `diff` in months/years when the two dates are in different calendars.                                                                   | Convert `b` into `a`'s calendar and count whole units there. A month counts when the day-of-month is reached, clamped per N-013.                                                                                                    |
| N-015 | gap      | `toGeezNumeral(0)` and negative numbers: Ge'ez has no zero.                                                                             | Throw `RangeError` for 0, negatives and non-integers.                                                                                                                                                                               |
| N-016 | gap      | Meskel, Genna and Timket after leap years (Genna on Tahsas 29 or 28).                                                                   | Open. Blocks T-042. **Owner to confirm** with an official source (T-041).                                                                                                                                                           |
| N-017 | gap      | Official list of Ethiopian public holidays and the authority for Eid confirmations.                                                     | Open. Blocks T-042 and T-065. **Owner to confirm** (T-041).                                                                                                                                                                         |
| N-018 | gap      | Afaan Oromo, Tigrinya and Arabic month, weekday and holiday names.                                                                      | Open. Blocks T-026 and T-044. Names come from the owner or native speakers, never invented.                                                                                                                                         |
| N-019 | gap      | Tsome Nebiyat start date and the Nineveh offset table are marked VERIFY.                                                                | Offsets are verified by the Fasika cross-check (R-HOL-08). Tsome Nebiyat stays open until the owner confirms.                                                                                                                       |
| N-020 | risk     | An unrelated npm package `qen.js` (Ethiopian dates) exists.                                                                             | Accepted; our packages are scoped under `@qen`, which the owner owns.                                                                                                                                                               |
| N-021 | conflict | Owner mentioned Electron; PLAN.md says Tauri.                                                                                           | Tauri, confirmed by the owner. ADR-0008.                                                                                                                                                                                            |
| N-022 | gap      | Is a native mobile app in scope?                                                                                                        | No. The website PWA covers phones. A native app would be a new milestone. ADR-0009.                                                                                                                                                 |
| N-023 | risk     | Google Calendar's DOM changes without notice.                                                                                           | Selectors in one module, saved HTML fixtures in tests, overlay disables itself when selectors miss.                                                                                                                                 |
| N-024 | gap      | Locale identifiers.                                                                                                                     | BCP 47: `en`, `am`, `om`, `ti`, `ar`.                                                                                                                                                                                               |
